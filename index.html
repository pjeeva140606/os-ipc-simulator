💡 Concept: Message Passing

Processes communicate by exchanging messages through send() and receive() primitives. Communication can be direct (naming the recipient) or indirect (via a shared mailbox). A blocking send waits for the receiver's acknowledgement; a non-blocking send returns immediately. Reliable delivery uses sequence numbers, ACKs, and timeout-based retransmission.

💡 Concept: Semaphores

A semaphore is a synchronization primitive with an integer value and two atomic operations: wait() (decrement; block if value < 0) and signal() (increment; unblock one waiting process). A binary semaphore (0 or 1) acts as a mutex. In Producer-Consumer, three semaphores coordinate access: empty (free slots), full (filled slots), and mutex (critical-section guard).

💡 Concept: Shared Memory & Race Conditions

In shared-memory IPC, processes read and write a common memory region. Without synchronization, concurrent access causes race conditions: the outcome depends on the execution order. A classic example is two processes incrementing a shared counter—lost updates occur when read-modify-write steps interleave. A mutex (mutual exclusion) protects the critical section to ensure correctness.
